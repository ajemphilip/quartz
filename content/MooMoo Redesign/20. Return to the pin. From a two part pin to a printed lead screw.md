# Goals
- Reopen the pin design after the first workbook and record where the redesign started
- Move the pin drive from a metal screw and nut to a lead screw, nut and motor holder that are all 3D printed
- Describe the whole actuator in one parametric OpenSCAD file so every later change is a number and not a redraw

# Description
The first workbook closed with a pin that was pushed up and down by a geared DC motor turning a metal screw inside a printed casing (see [[6. New Motor testing and Pin Reconstruction]]). That design worked, but the same three problems kept coming back. The pin blocked at the end of its travel (see [[2. Pin Block and Movement Solutions. Device exterior pin holder casing preparation]] and [[10. Motor block aluminum sensor and AI-Thinker Board]]). The button only clicked when the braille cap was pressed in its centre. The square pin wobbled a little while it moved.

The redesign folder shows that the work restarted in November 2025 with small exports of the old two part pin, and that by the end of December the pin had been replaced by a new actuator written in OpenSCAD with the BOSL2 library. This step documents that change. The later steps each pick up one part of the new actuator or the casing around it.

Reading the dates back, the first file of the whole redesign is not a pin at all. It is a screw and a square nut. The thread idea was already on the table eight days before the last round of pin variants was exported. The three pin variants of 10 November were saved 35 minutes and then 104 minutes apart, which reads like a print, try, adjust loop on a part that was already close to its limit. After 16 November nothing in the pin family was saved again. Six weeks later, late on 28 December, the new actuator appears as a complete file and its first three parts are exported the next afternoon. The casing shells in step 21 were being exported in those same days, so the pin and the box around it were redesigned together.

The folder also holds three clay printer parts from 27 and 28 November (`ScrewClayPrinter.stl`, `SyringeClayPrinter.stl`, `HousingPumpClayPrinter.stl`). They belong to a different project and are left out of this workbook.

## First thread test
![[MooMooRedesign_20_screwnut_nov2025.png]]
ScrewNut.scad rendered in OpenSCAD

```
include <BOSL2/std.scad>
include <BOSL2/screws.scad>
$fa=1.5;
$fs= 0.1;

 screw("M5x1,98");
 nut("M5x1",shape="square");
```

The square nut matters for everything that follows. A square nut cannot turn inside a square channel, so it can only travel along the screw. That is the principle of the elevator in the new actuator.

### Code
```
include <BOSL2/std.scad>
include <BOSL2/threading.scad>

$fs = 0.1;
$fa = 1;

// =============== PARAMETERS ===============

// Motor cover
MOTOR_COVER_HEIGHT = 19;
MOTOR_COVER_OUTER_R = 4;
MOTOR_COVER_INNER_R = 3.1;

// Bridge
BRIDGE_OUTER_SIZE = [11, 11, 40];
BRIDGE_INNER_SIZE = [12, 7, 35];
BRIDGE_Z = 29.5;

// Threaded rod (screw)
ROD_Z = 32;
ROD_D = 5;
ROD_HEIGHT = 35;
ROD_PITCH = 1.5;

// D-shaft
DSHAFT_BASE_Z = 27;
DSHAFT_BASE_HEIGHT = 3;
DSHAFT_BASE_R = 3;
DSHAFT_HOLE_R = 1.05;
DSHAFT_KEY_OFFSET = 1.5;
DSHAFT_KEY_SIZE = 2;

// Threaded nut
NUT_Z = 32;
NUT_WIDTH = 5.5;
NUT_ID = 5;
NUT_HEIGHT = 5;
NUT_PITCH = 1.5;
NUT_SLOP = 0.05;

// Screw hole
SCREW_HOLE_HEIGHT = 10;
SCREW_HOLE_R = 3.2;
SCREW_HOLE_Z = 40;

// Grip dots
DOT_R = 0.4;
DOT_OFFSET = 3;

// Inner cylinder cutout
INNER_CYL_HEIGHT = 19.1;
INNER_CYL_R = 3;
INNER_CYL_Z = 5;

// =============== MODULES ===============

module bottomMotorCover() {
    difference() {
        cylinder(MOTOR_COVER_HEIGHT, MOTOR_COVER_OUTER_R, MOTOR_COVER_OUTER_R, center=true);
        cylinder(MOTOR_COVER_HEIGHT + 0.1, MOTOR_COVER_INNER_R, MOTOR_COVER_INNER_R, center=true); 
    }
}

module bridge() {
    difference() {
        translate([0, 0, BRIDGE_Z])
            cube(BRIDGE_OUTER_SIZE, center=true); 
        translate([0, 0, BRIDGE_Z])
            cube(BRIDGE_INNER_SIZE, center=true);   
    }
}

module screwHole() {
    cylinder(SCREW_HOLE_HEIGHT, SCREW_HOLE_R, SCREW_HOLE_R);
}

module gripDots() {
    translate([DOT_OFFSET, 0, 0])
        sphere(DOT_R);
    translate([-DOT_OFFSET, 0, 0])
        sphere(DOT_R);
    translate([0, -DOT_OFFSET, 0])
        sphere(DOT_R);
    translate([0, DOT_OFFSET, 0])
        sphere(DOT_R);
}

module dShaftBase() {
    difference() {
        translate([0, 0, DSHAFT_BASE_Z])
            cylinder(DSHAFT_BASE_HEIGHT, DSHAFT_BASE_R, DSHAFT_BASE_R);
        translate([0, 0, DSHAFT_BASE_Z - 1])
            cylinder(DSHAFT_BASE_HEIGHT + 1, DSHAFT_HOLE_R, DSHAFT_HOLE_R);
    }
}

module dShaftKey() {
    translate([DSHAFT_KEY_OFFSET, 0, DSHAFT_BASE_Z + 1])
        cube(DSHAFT_KEY_SIZE, center=true);
}

module dShaft() {
    dShaftBase();
    dShaftKey();
}

module threadedRod() {
    translate([0, 0, ROD_Z])
        threaded_rod(d=ROD_D, height=ROD_HEIGHT, pitch=ROD_PITCH);
}

module threadedNutPart() {
    translate([0, 0, NUT_Z])
        threaded_nut(nutwidth=NUT_WIDTH, id=NUT_ID, h=NUT_HEIGHT, pitch=NUT_PITCH, $slop=NUT_SLOP);
}

module bridgeWithHoles() {
    difference() {
        bridge();
        translate([0, 0, INNER_CYL_Z])
            cylinder(INNER_CYL_HEIGHT, INNER_CYL_R, INNER_CYL_R, center=true); 
        translate([0, 0, SCREW_HOLE_Z])
            screwHole();
    }
}

module mainBody() {
    union() {
        bottomMotorCover();
        bridgeWithHoles();
    }
}

// =============== MAIN ASSEMBLY ===============

module assembly() {
    gripDots();
    dShaft();
    threadedRod();
    threadedNutPart();
    mainBody();
}

// Render the assembly
assembly();
```

# Critical Reflection
## Moving from drawn parts to a parametric file
The November pins exist only as exports, so every variant had to be redrawn and exported again. From 28 December on the actuator is a list of named numbers at the top of one file. The later steps show what that made possible. The pitch went from 1.5 to 4.5 and then to 3 mm, the nut clearance from 0.05 to 0.08 and then to 0.11, and the motor cover from 3.1 to 3.2 mm, each by changing one line.

**Pros**
- The screw, the nut and the motor holder share one coordinate system, so a change to one part shows its effect on the others at once
- The square nut in a square channel removes the need for a separate guide rail, which note 6 had asked for
- Nothing in the drive is a bought metal part any more except the motor

**Cons**
- A 1.5 mm pitch on a 5 mm printed rod leaves very small thread flanks. Step 22 shows the pitch being tested again and step 26 shows it settling at 3 mm
- The motor cover is a closed tube in this version, so the motor can only be pushed in from one end. Step 24 deals with that
