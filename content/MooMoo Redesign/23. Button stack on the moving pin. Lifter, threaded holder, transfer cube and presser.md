# Goals
- Carry a push button on top of the moving elevator so that every braille dot is also an input
- Hold the button by its own thread so it can be taken out without tools
- Pass the press from the braille cap down to the button in a straight line
- Keep a path for the two button wires through every part of the stack

# Description
In the first workbook the button sat in a printed holder on top of the pin, and the reflection of [[6. New Motor testing and Pin Reconstruction]] recorded that it only clicked when the cap was pressed in the centre. [[7. A comparison between other buttons prototypes and different motors speeds]] then compared three buttons. The redesign keeps the idea of one button per dot and rebuilds everything around it as a stack of small round parts that ride on the elevator of step 20.

The stack was drawn in the first three weeks of January 2026 and changed once more on 3 March, when the threaded holder was split into two halves. The order from bottom to top is the lifter, which slides over the bridge of the shaft body and is carried by the two side pins of the elevator, the threaded holder that grips the button, the transfer part that plugs into the lifter with a cube, and the presser that closes the stack from above.

Reading the dates back, the stack grows from the bottom up. The adapter to the screw comes first on 7 January, then the transfer part, then the housings, and the presser that closes the top arrives last on 21 January. 11 January is the day it came together. A file is saved at 07:34 in the morning and the day ends with three exports inside three minutes, which is what queuing a full set for the printer looks like. After that the stack rests for about a month while the thread tests of step 22 run. When it comes back at the end of February the changes are small and precise. The lifter loses 0.3 mm of width, and the holder is split so that it can close around the button from the sides.

| Part | Main values |
|---|---|
| Lifter, `elevatorLifterWButtonCube.scad` | Square tunnel 13.3 mm outside and 11.3 mm inside, 37 mm tall. One slot 1.7 mm wide and 9 mm tall for the elevator pins. A square button holder of the same section on top, 13.5 mm tall |
| Threaded holder, `buttonHolderScrew.scad` | Cylinder of radius 8.5 and 6.5 mm, 26 mm tall. An M14 thin nut from BOSL2 hollowed into its wall so the button screws in. Two slanted cable holes of radius 3 mm. A torus ring and four grip dots of radius 0.7 mm |
| Transfer part, `buttonTransferWCube.scad` | Cube of 11.2 by 11.2 by 12 mm that drops into the 11.3 mm holder of the lifter. Cylinder of radius 10.6 and 8.6 mm, 10 mm tall, with cross slots 2 mm wide |
| Presser, `buttonPresserCircular.scad` | Cylinder of radius 10.6 and 8.6 mm, 14 mm tall, with cross slots 2 mm wide and a top tube of radius 5 and 3 mm |
| First casing, `buttonCasing.scad` | Radius 11.7 and 8.6 mm, 26 mm tall, cross slots 5 mm wide in four directions, a spherical cut of radius 10 mm |

The cube is the detail that carries over into every later version. A cube of 11.2 mm in a holder of 11.3 mm cannot turn once it is seated, so the button wires do not twist while the dot travels.

## Splitting the holder, 3 March 2026
![[MooMooRedesign_23_split_holder_mar2026.png]]
1 and 2 the two exports of 3 March, 3 `TransferCubeButtonNew`, 4 the left half of the split cylinder as it stood in May 2026

A button with a threaded body can be screwed into a closed holder, but its wires then have to be fed through the holder first. Cutting the holder in two lets it close around a button that is already wired. `buttonCylinderTriangleSplit.scad` does this with a cut 0.35 mm wide and two three sided alignment pins of radius 1.15 mm that enter holes of radius 1.4 mm in the other half.

## Code
### Lifter
```
include <BOSL2/std.scad>
include <BOSL2/threading.scad>

$fa = 0.5;
$fs = 0.01;

// ======================================
// Parameters
// ======================================

// Elevator pins
ELEVATOR_PIN_OFFSET = 7;
ELEVATOR_PIN_R = 1;
ELEVATOR_PIN_LENGTH = 3;
ELEVATOR_PIN_Z = 9;

// Tunnel
//Prev 13.6
TUNNEL_OUTER_SIZE = 13.3;
TUNNEL_INNER_SIZE = 11.3;
TUNNEL_HEIGHT = 37;
TUNNEL_Z = 18.5;

// Slot
SLOT_LENGTH = 30;
SLOT_WIDTH = 1.7;
SLOT_HEIGHT = 9;
SLOT_Z = 4.5;

// Top button holder
BUTTON_HOLDER_OUTER_SIZE = 13.3;
BUTTON_HOLDER_INNER_SIZE = 11.3;
BUTTON_HOLDER_OUTER_HEIGHT = 13.5;
BUTTON_HOLDER_INNER_HEIGHT = 20;
BUTTON_HOLDER_Z = 40.75;

// Grip dots
DOT_R = 0.5;
DOT_OFFSET = 5.85;
Z_OFFSET = 45;

// ======================================
// Top button holder
// ======================================

module topButtonHolder() {
    difference() {
        translate([0, 0, BUTTON_HOLDER_Z])
            cube([BUTTON_HOLDER_OUTER_SIZE, BUTTON_HOLDER_OUTER_SIZE, BUTTON_HOLDER_OUTER_HEIGHT], center=true);
        
        translate([0, 0, BUTTON_HOLDER_Z - 3])
            cube([BUTTON_HOLDER_INNER_SIZE, BUTTON_HOLDER_INNER_SIZE, BUTTON_HOLDER_INNER_HEIGHT], center=true);
    }
}

// ======================================
// Tunnel
// ======================================

module tunnel() {
    difference() {
        translate([0, 0, TUNNEL_Z])
            cube([TUNNEL_OUTER_SIZE, TUNNEL_OUTER_SIZE, TUNNEL_HEIGHT], center=true);
        
        translate([0, 0, TUNNEL_Z])
            cube([TUNNEL_INNER_SIZE, TUNNEL_INNER_SIZE, TUNNEL_HEIGHT], center=true);
    }
}

// ======================================
// Threaded nut elevator
// ======================================

module threadedNutElevator() {
    translate([ELEVATOR_PIN_OFFSET, 0, ELEVATOR_PIN_Z])
        rotate([0, 90, 0])
            cylinder(ELEVATOR_PIN_LENGTH, ELEVATOR_PIN_R, ELEVATOR_PIN_R, center=true);
    
    translate([-ELEVATOR_PIN_OFFSET, 0, ELEVATOR_PIN_Z])
        rotate([0, 90, 0])
            cylinder(ELEVATOR_PIN_LENGTH, ELEVATOR_PIN_R, ELEVATOR_PIN_R, center=true);
}

// ======================================
// Grip dots
// ======================================

module gripDots() {
    translate([DOT_OFFSET, 0, Z_OFFSET])
        sphere(DOT_R);
    
    translate([-DOT_OFFSET, 0, Z_OFFSET])
        sphere(DOT_R);
    
    translate([0, -DOT_OFFSET, Z_OFFSET])
        sphere(DOT_R);
    
    translate([0, DOT_OFFSET, Z_OFFSET])
        sphere(DOT_R);
}

// ======================================
// Assembly
// ======================================

module assembly() {
gripDots();
    difference() {
        union() {
            tunnel();
            topButtonHolder();
        }
        
        translate([0, 0, SLOT_Z])
            cube([SLOT_LENGTH, SLOT_WIDTH, SLOT_HEIGHT], center=true);
        
        threadedNutElevator();
    }
}

assembly();
```

### Threaded holder
```
include <BOSL2/std.scad>
include <BOSL2/screws.scad>

$fa = 1;
$fs = 0.1;

// ======================================
// Parameters
// ======================================

CYLINDER_OUTER_RADIUS = 8.5;
CYLINDER_INNER_RADIUS = 6.5;
CYLINDER_HEIGHT = 26;
CYLINDER_Z = 11;

CABLE_HOLE_RADIUS = 3;
CABLE_HOLE_LENGTH = 11;

GRIP_DOT_RADIUS = 0.7;
GRIP_DOT_DISTANCE = 8.5;
GRIP_DOT_TOP_Z = 21.5;

TORUS_MAJOR_DIAMETER = 17.5;
TORUS_OUTER_DIAMETER = 18.5;
TORUS_Z = 18;

NUT_Z = 17;
NUT_HOLLOW_Z = 21.5;
NUT_HOLLOW_OUTER_RADIUS = 14;
NUT_HOLLOW_INNER_RADIUS = 8;
NUT_HOLLOW_HEIGHT = 10;

// ======================================
// Cylinder top
// ======================================

module cylinderTop() {
    translate([0, 0, CYLINDER_Z])
        difference() {
            cylinder(CYLINDER_HEIGHT, CYLINDER_OUTER_RADIUS, CYLINDER_OUTER_RADIUS, center=true);
            cylinder(CYLINDER_HEIGHT + 2, CYLINDER_INNER_RADIUS, CYLINDER_INNER_RADIUS, center=true);
        }
}

// ======================================
// Cable holes
// ======================================

module cableHoles() {
    rotate([45, 0, 90])
        translate([0, 2, -6])
            cylinder(CABLE_HOLE_LENGTH, CABLE_HOLE_RADIUS, CABLE_HOLE_RADIUS, center=true);
    
    rotate([45, 0, -90])
        translate([0, 2, -6])
            cylinder(CABLE_HOLE_LENGTH, CABLE_HOLE_RADIUS, CABLE_HOLE_RADIUS, center=true);
}

// ======================================
// Grip dots
// ======================================

module gripDots() {
    translate([0, GRIP_DOT_DISTANCE, 0]) 
        sphere(r=GRIP_DOT_RADIUS);
    
    translate([0, -GRIP_DOT_DISTANCE, 0]) 
        sphere(r=GRIP_DOT_RADIUS);
    
    translate([GRIP_DOT_DISTANCE, 0, 0]) 
        sphere(r=GRIP_DOT_RADIUS);
    
    translate([-GRIP_DOT_DISTANCE, 0, 0]) 
        sphere(r=GRIP_DOT_RADIUS);
}

// ======================================
// Grip dots on top
// ======================================

module gripDotsTop() {
    translate([0, 0, GRIP_DOT_TOP_Z])
        gripDots();
}

// ======================================
// Torus ring
// ======================================

module torusRing() {
    translate([0, 0, TORUS_Z])
        torus(d_maj=TORUS_MAJOR_DIAMETER, od=TORUS_OUTER_DIAMETER);
}

// ======================================
// Hollowed nut
// ======================================

module hollowedNut() {
    difference() {
        translate([0, 0, NUT_Z])
            nut("M14", thickness="thin");
        
        translate([0, 0, NUT_HOLLOW_Z])
            difference() {
                cylinder(NUT_HOLLOW_HEIGHT, NUT_HOLLOW_OUTER_RADIUS, NUT_HOLLOW_OUTER_RADIUS, center=true);
                cylinder(NUT_HOLLOW_HEIGHT, NUT_HOLLOW_INNER_RADIUS, NUT_HOLLOW_INNER_RADIUS, center=true);
            }
    }
}

// ======================================
// Top with holes
// ======================================

module topWithHoles() {
    difference() {
        cylinderTop();
        cableHoles(); 
    }
}

// ======================================
// Assembly
// ======================================

module assembly() {
    topWithHoles();
    gripDots();
    gripDotsTop();
    torusRing();
    hollowedNut();
}

assembly();
```

# Critical Reflection
## A stack of small parts against one button holder
**Pros**
- Each part has one job, so a fault can be fixed by printing again a part that is 10 to 37 mm tall
- The button is held by its own thread and can be replaced without glue
- The cube and the cross slots fix the rotation of every part, which keeps the wires from twisting when the dot travels

**Cons**
- The stack adds height. The lifter alone is 47.5 mm tall, and the holder, the transfer part and the presser sit on top of it
- Every joint in the stack adds a little play, and six stacks add six times the printing and the assembly
- The first round casing of 10 January with its wide slots and spherical cut does not appear again after that week, so part of January went into a direction that was dropped
