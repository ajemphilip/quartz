# Goals
- Let Moo Local, the computer that does Moo's listening, stories and voice, run on Windows, Mac and Linux
- Install it without typing anything in a Terminal
- Offer the right download on the website for whatever computer opens it, and keep the other systems in reach
- Keep Moo Local running after the computer restarts, without anyone starting it again
- Let the parent choose which models to download, and refuse a model that is too big for the computer

# Description
In step 34 a Mac with an Apple chip installed Moo Local with one line pasted into Terminal. The maker said the Terminal is always difficult and asked for an easier setup, then said it should work on Windows, Mac and Linux. On the website he wanted an option to connect a local machine whatever its system, and something robust and simple in place of the Terminal.

Moo Local's story part already ran on every system through Ollama. Its listening and three of its voices used Apple's MLX, which runs only on Macs with Apple chips. Moo Local now picks its parts by the computer it is on, and the Moo hands out an installer for each system as a file to download and open. The Set up a local machine page offers that file first for the visitor's computer.

# How it works
## What runs where
| Part | Mac with an Apple chip | Windows, Linux, Mac with an Intel chip |
|---|---|---|
| Story | Ollama, Gemma 3 4B downloaded | The same |
| Listening | Whisper through mlx-whisper | The same Whisper sizes through faster-whisper, on an NVIDIA card when one works, otherwise on the processor |
| Voices everywhere | Kokoro, Piper, Supertonic, Pocket, the small Kitten 2 models (Pico, Nano, Mini) | The same. On an Intel Mac without Pocket and Kitten 2, which need a newer PyTorch than Intel Macs can have |
| Voices only here | The Mac's own voices, Orpheus, Qwen3, the full Kitten 2 | Not offered |
| Found by the Moo | Announced through macOS's own network service | Announced by Moo Local itself |

The list of voices that Moo Local sends to the Moo names only what works on that computer. If the Moo asks a Windows computer for a voice of the Mac, the line is spoken with Kitten 2 small or Kokoro.

## Three downloads
| System | The file | What the computer asks once, since the files are not signed |
|---|---|---|
| Windows | `Install Moo Local.cmd` | SmartScreen: More info, then Run anyway. Near the end a Yes, so the Moo can reach the computer through the firewall |
| Mac | `Install Moo Local.command`, inside a zip that Safari opens by itself | If the Mac says it cannot check the file: System Settings, Privacy and Security, Open Anyway. On older macOS: right-click the file and choose Open |
| Linux | `Install Moo Local.sh` | Allow it to run as a program in the file's properties. Ollama's own installer asks for the password |

A `.command` file downloaded on its own loses the permission to run. Inside a zip it keeps it, so the Mac gets a zip. Each file has the Moo's address filled in by the Moo as it hands the file out, as a number rather than `moo.local`, because some computers cannot look up names that end in `.local`.

## What the installer does
1. Fetches Moo Local's files from the Moo
2. Fetches uv, a small program that brings its own Python 3.12. No Python, Homebrew or administrator is needed
3. Finds Ollama, or installs it. On a Mac a copy goes into the home folder, on Windows it comes from winget or from Ollama's own installer, on Linux from Ollama's own script
4. Installs Moo Local's libraries, and Kitten 2's libraries in an environment of their own
5. Downloads no AI model. In the first version of this step it downloaded Gemma 3 4B and the voices, about 6 GB; after the maker's request below it installs only Moo Local itself, about 2 GB of programs
6. Starts Moo Local and sets it to start at every login: a LaunchAgent on a Mac, the Startup folder on Windows, a user service on Linux
7. Waits until Moo Local answers, then says that the computer now appears under Local machines

Everything goes into the home folder. Running the file again updates Moo Local and skips what is already there. The Terminal line of step 34 does the same as the Mac and Linux downloads and stays on the page as an alternative.

## The page
The Set up a local machine page shows one large button, Download for Windows, Mac or Linux, chosen by the system of the computer that opens it. The other two systems are links under it, and below them is how to open that file. On a phone or tablet the page says to open it on the computer that should do the work. The Terminal line is folded away under Or with a Terminal line.

## Models chosen by the parent
Looking at the settings of Moo Local on the AI engine screen, the maker asked for all local models to be available to install but not installed, for the user to select them, and for an error when a model is too big, so that a smaller one is chosen. Commit `80a957d`.

The settings card of a local machine now has a part called Models, in three groups: Story, Listening and Voice. Each model shows its download size and the memory it needs, with Install or Remove. A download shows its progress, one at a time, and the new model then appears in the choices below. Nothing is downloaded until the parent taps Install.

| Check | When | What the parent sees |
|---|---|---|
| Memory | Before installing, and again each time a story, listening or large voice model is used | "Gemma 3 12B is too big for this computer: it needs about 10.4 GB of memory and this computer has 8 GB. Try Gemma 3 4B instead." The Install button stays grey |
| Free disk | Before installing | How much space it needs and how much is free |
| Nothing installed | When the Moo asks for a story, listening or a voice | Which kind of model is missing, and that it is chosen under Models |

A model may use up to 70 percent of the computer's memory, since the system and the other models need the rest. A story model needs about 1.25 times its download plus half a gigabyte for the story so far; the other models about 1.3 times their download. For a story model the suggestion is the best scorer of step 32 that fits; for the others the next smaller of the same kind. On an 8 GB computer this allows Gemma 3 4B and refuses Qwen 2.5 7B, Llama 3.1 8B, Mistral Nemo and Gemma 3 12B. On the maker's 16 GB Mac it allows Gemma 3 12B.

## One dropdown for each kind
The maker then asked for the same with less space: the parent only selects a model, one is uninstalled and the other installed, in a dropdown. Commit `3d7228d`, installed on the Moo the same afternoon.

The settings card of a local machine now has three dropdowns: Story model, Listening model and Voice model. Each lists every model with its size and the memory it needs, and a model too big for the computer is listed but cannot be picked. Picking a model downloads it, with the progress under the dropdown. Moo Local then loads it once and makes a few words, and only then removes the model it replaces, so each kind keeps one model on the computer. A model that does not run is removed again and the old one is kept, with the reason shown. The Moo then uses the new model by itself. The separate choices of story and listening model are gone, and the voice choice is now called Voice in use, which on a Mac also offers the Mac's own voices.

## The one selected is the one in use
Seeing a voice model dropdown, then a choice called Voice in use, then the voice itself, the maker asked why there were three things, since the one in use is the one selected. Commit `e7e5084`. Each dropdown now shows the model in use, and picking one puts it in use, downloading it first if it is not on the computer. Under the voice dropdown only the choice of speaker stays, such as Samantha or Heart. The Mac's own voices are in the voice dropdown as a model that is built in, never downloaded or removed, and Moo Local speaks with them when no other voice is installed.

# Critical Reflection
**Pros**
- A parent opens one file and answers the computer's own questions. Nothing is typed
- One page for every computer, with the right file first
- Moo Local starts again by itself after a restart, which step 34 left to the parent
- No administrator password on Mac or Windows, apart from the firewall Yes on Windows
- The voice list only offers what the computer can speak
- Nothing is downloaded without the parent's choice, and a model too big for the computer is refused before the download, with a smaller one named

**Cons**
- The files are not signed, so each system warns once and the parent must know where to click. Signing needs Apple's and Microsoft's paid programs
- About 2 GB of programs and a wait the first time, before any model
- A fresh computer cannot tell a story until the parent has installed a story, listening and voice model
- The memory each model needs is an estimate from its size, not a measurement
- Linux still asks for a password, for Ollama's installer
- On Windows and Linux listening runs on the processor unless an NVIDIA card is set up, so the largest Whisper size is slow there
- Intel Macs lose Pocket and Kitten 2
- Nothing on Windows or Linux has been tried on a real computer yet
