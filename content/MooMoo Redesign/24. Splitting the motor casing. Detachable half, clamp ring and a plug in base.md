# Goals
- Make the motor removable without breaking or reprinting the actuator body
- Make the whole actuator a module that plugs into the bottom shell and can be pulled out again
- Give the module a defined depth in its socket so that all six dots start from the same height

# Description
Up to March 2026 the motor sat in a closed tube at the bottom of the shaft body and had to be fed in along the axis of the body together with its wires. This step turns the shaft body into a small module with three printed parts. The main casing keeps the bridge, the square base and one half of the motor cover. The detachable half closes the motor cover from the side. A clamp ring with a bolt holds the two halves together around the motor.

The module is what plugs into the bottom shell. Its square base of 8.1 mm drops into a socket of 8.45 mm (step 21), four grip dots near the foot of the base give it a click, and the motor wires leave through a slanted hole in the base. The last change of this step is a thin square plate above the base, saved under the name Kraweznik, Polish for curb, which stops the module at a fixed depth.

## How the split is made
`ShaftBody.scad` builds the whole body once in a module called `assembly()` and then cuts it. A block of 20 by 20 by 21 mm, anchored on its left face and starting 9 mm below the origin, removes one side of the motor cover over its full height. What is left is the main casing. The piece that the block removed is kept as the detachable half and is trimmed by 3 mm at the top and at the bottom so that it can be pushed in from the side. Both parts share a ring shaped cut of radius 5 and 4.2 mm, 6 mm tall, which forms a seat 0.3 mm deep around the motor cover. The clamp ring sits in that seat and cannot slide along the motor.

| Feature | Value |
|---|---|
| Square base | 8.1 by 8.1 mm, 20 mm tall, for a socket of 8.45 mm |
| Cable hole through the base | Radius 3 mm, tilted 45 degrees, squeezed to 70 percent of its width |
| Grip dots on the base | Four, radius 0.5 mm, later 0.7 mm, placed 4 mm from the axis |
| Grip dots on the body | Three rings of four, radius 0.4 mm |
| Motor cover | Bore 6.4 mm, outside 9 mm, 19 mm tall |
| Bridge | 11 by 11 by 40 mm with a channel 7 mm wide for the elevator |
| Seat for the clamp ring | Between radius 4.2 and 5 mm, 6 mm tall. Raised by 3 mm on both parts in the 11 May file |
| Stopper plate | 9 by 9 by 1 mm, 12.6 mm below the origin, shifted 0.45 mm so one face lines up with the base |

The stopper plate is 9 mm wide and the socket is 8.45 mm, so the plate cannot enter the socket. It rests on the rim of the socket and sets the depth. Below the plate 15.9 mm of the base remain, a little more than the 15 mm height of the socket wall, so the foot of the base reaches into the square opening in the floor of the bottom shell.

## Code
### Shaft body with stopper
```
include <BOSL2/std.scad>
include <BOSL2/threading.scad>

$fa = 0.5;
$fs = 0.01;

// ======================================
// Parameters
// ======================================

// Base cube
BASE_CUBE_SIZE = 8.1;
BASE_CUBE_Z = -19;
BASE_CUBE_HOLE_R = 3;
BASE_CUBE_HOLE_Z = -10;

// Motor cover
MOTOR_COVER_HEIGHT = 19;
MOTOR_COVER_OUTER_R = 4.5;
MOTOR_COVER_INNER_R = 3.2;

// Bridge
BRIDGE_OUTER_SIZE = [11, 11, 40];
BRIDGE_INNER_SIZE = [12, 7, 35];
BRIDGE_Z = 29.5;

// Screw hole at top of bridge
SCREW_HOLE_HEIGHT = 10;
SCREW_HOLE_R = 3.2;
SCREW_HOLE_Z = 40;

// Inner cylinder cutout in bridge
INNER_CYL_HEIGHT = 19.1;
INNER_CYL_R = 3.2;
INNER_CYL_Z = 5;

// Torus ring
TORUS_MAJOR_DIAMETER = 6.3;
TORUS_OUTER_DIAMETER = 7;
TORUS_Z = -6.5;

// Grip dots on body
DOT_R = 0.4;
DOT_OFFSET = 3;

// Grip dots on base cube
DOT_R_CUBE = 0.7;
DOT_OFFSET_CUBE = 4.0;
Z_OFFSET_CUBE = -25;

// Snap groove at the split
GROOVE_HEIGHT = 6;
GROOVE_OUTER_R = 5;
GROOVE_INNER_R = 4.2;

// Right half cutter (splits the casing)
SPLIT_CUTTER_SIZE = [20, 20, 21];
SPLIT_CUTTER_Z = -9;

// Top and bottom trims on detachable half
HALF_TRIM_SIZE = [20, 20, 3];
HALF_TRIM_Z_TOP = 11.9;
HALF_TRIM_Z_BOT = -11.9;

// Bottom stopper
STOPPER_SIZE = [9, 9, 1];
STOPPER_Z = -12.6;
STOPPER_X_OFFSET = -0.45;   // shift so +X face aligns with base cube +X face

// ======================================
// Geometry modules
// ======================================

module angledHole() {
    scale([0.7, 1, 1])
        translate([0.99, 0, BASE_CUBE_HOLE_Z])
            rotate([0, -45, 0])
                cylinder(35, BASE_CUBE_HOLE_R, BASE_CUBE_HOLE_R, center=true);
}

module baseCube() {
    difference() {
        translate([0, 0, BASE_CUBE_Z])
            cube([BASE_CUBE_SIZE, BASE_CUBE_SIZE, 20], center=true);
        angledHole();
    }
}

module bottomMotorCover() {
    difference() {
        cylinder(MOTOR_COVER_HEIGHT, MOTOR_COVER_OUTER_R, MOTOR_COVER_OUTER_R, center=true);
        cylinder(MOTOR_COVER_HEIGHT + 0.1, MOTOR_COVER_INNER_R, MOTOR_COVER_INNER_R, center=true);
        scale([0.7, 1, 1])
            translate([0.99, 0, BASE_CUBE_HOLE_Z])
                rotate([0, -45, 0])
                    cylinder(5, BASE_CUBE_HOLE_R, BASE_CUBE_HOLE_R, center=true);
    }
}

module bridge() {
    difference() {
        translate([0, 0, BRIDGE_Z])
            cube(BRIDGE_OUTER_SIZE, center=true);
        translate([0, 0, BRIDGE_Z])
            cube(BRIDGE_INNER_SIZE, center=true);
    }
}

module screwHole() {
    cylinder(SCREW_HOLE_HEIGHT, SCREW_HOLE_R, SCREW_HOLE_R);
    translate([3, 0, 10])
        cube(6.47, center=true);
}

module bridgeWithHoles() {
    difference() {
        bridge();
        translate([0, 0, INNER_CYL_Z])
            cylinder(INNER_CYL_HEIGHT, INNER_CYL_R, INNER_CYL_R, center=true);
        translate([0, 0, SCREW_HOLE_Z])
            screwHole();
    }
}

module gripDots() {
    xcopies(spacing=DOT_OFFSET * 2, n=2) sphere(DOT_R);
    ycopies(spacing=DOT_OFFSET * 2, n=2) sphere(DOT_R);
}

module gripDotsCube() {
    translate([0, 0, Z_OFFSET_CUBE]) {
        xcopies(spacing=DOT_OFFSET_CUBE * 2, n=2) sphere(DOT_R_CUBE);
        ycopies(spacing=DOT_OFFSET_CUBE * 2, n=2) sphere(DOT_R_CUBE);
    }
}

module torusRing() {
    translate([0, 0, TORUS_Z])
        torus(d_maj=TORUS_MAJOR_DIAMETER, od=TORUS_OUTER_DIAMETER);
}

module mainBody() {
    bottomMotorCover();
    bridgeWithHoles();
}

module bottomStopper() {
    difference() {
        translate([STOPPER_X_OFFSET, 0, STOPPER_Z])
            cube(STOPPER_SIZE, center=true);
        angledHole();
    }
}

// ======================================
// Full assembly (input to the split)
// ======================================

module assembly() {
    baseCube();
    rotate([0, 0, 45]) translate([0, 0, 10]) gripDots();
    rotate([0, 0, 45]) translate([0, 0, 5])  gripDots();
    rotate([0, 0, 45]) gripDots();
    mainBody();
    torusRing();
    gripDotsCube();
}

// ======================================
// Split tools (shared by both halves)
// ======================================

module snapGroove() {
    difference() {
        cylinder(GROOVE_HEIGHT, GROOVE_OUTER_R, GROOVE_OUTER_R);
        cylinder(GROOVE_HEIGHT, GROOVE_INNER_R, GROOVE_INNER_R);
    }
}

module rightHalfCutter() {
    translate([0, 0, SPLIT_CUTTER_Z])
        cuboid(SPLIT_CUTTER_SIZE, anchor=LEFT+BOTTOM);
}

// ======================================
// Part 1 - Main casing (left half with the gap)
// ======================================

module mainCasing() {
    difference() {
        assembly();
        translate([0, 0, 3])
            snapGroove();
        rightHalfCutter();
    }
}

// ======================================
// Part 2 - Detachable half (snaps into the gap)
// ======================================

module detachableHalf() {
    difference() {
        intersection() {
            assembly();
            rightHalfCutter();
        }
        translate([0, 0, 3])
            snapGroove();
        translate([0, 0, HALF_TRIM_Z_TOP])
            cuboid(HALF_TRIM_SIZE, anchor=BOTTOM);
        translate([0, 0, HALF_TRIM_Z_BOT])
            cuboid(HALF_TRIM_SIZE, anchor=BOTTOM);
    }
}

// ======================================
// Render - swap which line is active
// ======================================

mainCasing();
bottomStopper();
//detachableHalf();
```

### Clamp ring
```
$fa = 0.5;
$fs = 0.01;

// ======================================
// Parameters
// ======================================

RING_OUTER_R = 6.3;
RING_INNER_R = 4.5;
RING_HEIGHT = 6;

SLOT_SIZE = [3, 5, 10];
SLOT_Y = 6;

EAR_RIGHT_SIZE = [2, 6, 6];
EAR_RIGHT_POS = [2.5, 8, 0];

EAR_LEFT_SIZE = [5, 7, 6];
EAR_LEFT_POS = [-4, 8, 0];

BOLT_R = 1.4;
BOLT_LENGTH = 20;
BOLT_Y = 7.8;

// ======================================
// Geometry
// ======================================

module ring() {
    difference() {
        cylinder(RING_HEIGHT, RING_OUTER_R, RING_OUTER_R, center=true);
        cylinder(RING_HEIGHT, RING_INNER_R, RING_INNER_R, center=true);
    }
}

module slot() {
    translate([0, SLOT_Y, 0])
        cube(SLOT_SIZE, center=true);
}

module ears() {
    translate(EAR_RIGHT_POS) cube(EAR_RIGHT_SIZE, center=true);
    translate(EAR_LEFT_POS)  cube(EAR_LEFT_SIZE,  center=true);
}

module boltHole() {
    translate([0, BOLT_Y, 0])
        rotate([0, 90, 0])
            cylinder(BOLT_LENGTH, BOLT_R, BOLT_R, center=true);
}

module clamp() {
    difference() {
        union() {
            difference() {
                ring();
                slot();
            }
            ears();
        }
        boltHole();
    }
}

clamp();
```

# Critical Reflection
## The actuator as a module
**Pros**
- A motor can be changed by opening one bolt. Nothing has to be printed again
- The module leaves the shell as one piece, so an actuator can be tested on the desk and then plugged in
- The stopper plate removes one source of uneven dot height, because depth no longer depends on how hard the module was pushed in
- All fits are numbers at the top of one file. The clamp, the seat and the socket can each be tuned for a new printer or a new material

**Cons**
- The module is now three printed parts and a bolt where it used to be one part, and there are six modules
- A seat only 0.3 mm deep is close to the accuracy of the printer, so the clamp depends on the bolt and not on the seat
- The exports of the shaft body are between 130 and 316 MB each, because the file sets the BOSL2 resolution to `$fs = 0.01`. The OpenSCAD images on this page were rendered from the same sources at `$fs = 0.35`, which brings the main casing down to about 0.15 MB

## What the evening of 20 April shows
The first clamp was the elegant one. It was a snap ring that needs no hardware. It was exported twice within eleven minutes and set aside the same evening. The bolt clamp that replaced it is bulkier and needs a screw, and it is the one that stayed.
