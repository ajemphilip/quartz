# Goals
- Get one printed screw that holds the motor shaft, clears the shaft body and turns freely inside the printed nut
- Settle the pitch of the thread
- Print six elevator nuts in one go with a clearance that works for all of them

# Description
The lead screw is the smallest moving part of the actuator and the one with the most constraints. Its lower end has to grip a D shaped motor shaft in a hole of about 2.4 mm. Its thread has to run in a printed nut. Between the two it has to pass through the bore at the top of the motor cover without rubbing. Step 22 tested each of these alone. This step covers the day on which they were brought together in one part, 12 May 2026, when the screw was exported ten times between 09:34 and 16:18.

The screw was taken out of the actuator file and given its own source on 5 May (`screw.scad`). On the night of 11 May that file was copied under the name `screwReducedDshaftCylninder.scad` and the lower end was redesigned. The D shaft socket was shortened from 4.8 to 2 mm, a solid spacer disc of 3.6 mm was placed between the socket and the thread, and two thin keys were added along the side.

## The lower end of the screw
| Parameter | `screw.scad`, 5 May | `screwReducedDshaftCylninder.scad`, 12 May |
|---|---|---|
| D shaft socket height | 4.8 mm | 2 mm |
| D shaft hole radius | 1.05 mm | 1.21 mm |
| Key that forms the flat of the D | 2 mm cube, 1.5 mm off centre | 2.2 by 2.4 by 5 mm block, 1.65 mm off centre |
| Spacer between socket and thread | A cap cylinder 6.5 mm tall around the top of the socket | A solid disc of 3.6 mm |
| Side keys | One of 1 by 1 by 5 mm | Two of 1 by 1 mm, 9.9 and 8.4 mm long, on opposite sides |
| Thread | 5 mm diameter, 35 mm long, pitch 3 mm | The same |

The hole for the motor shaft grew from 2.1 to 2.42 mm across. The flat of the D moved from 0.5 to 0.55 mm from the axis. The socket itself became less than half as tall, and a solid disc now closes it off from the thread so that the shaft cannot push up into the threaded part.

With a single start thread the elevator rises by one pitch for every turn of the screw. The open window of the bridge is 35 mm tall and the nut is 5 mm tall, so the elevator can travel about 30 mm, which is ten turns at 3 mm. The Pi code of step 29 never runs a motor for longer than 1.5 seconds, so the real travel of a dot is set by the speed of the motor within that time.

## The elevator nut
The elevator is a square nut of 5.5 mm with a 5 mm bore and a pitch of 3 mm, set into a block of 11 by 6.7 by 5 mm. Two pins of radius 1 mm and length 3 mm stand out of the short sides, 7 mm from the axis. The pins reach through the slot of the lifter (step 23) and carry the button stack. The block is 6.7 mm wide for the 7 mm channel of the bridge, so it slides and cannot turn.

| Clearance, BOSL2 slop | File |
|---|---|
| 0.05 | `shaft mechanism.scad`, 28 Dec 2025 |
| 0.08 | `shaft mechanism.scad`, 28 Mar 2026 |
| 0.11 | `elevatorBiggerSlop.stl`, 12 May 2026 and `elevator.scad`, 14 May 2026 |

## Code
### Screw
```
include <BOSL2/std.scad>
include <BOSL2/threading.scad>

$fa = 0.5;
$fs = 0.01;

// D shaft base
DSHAFT_BASE_Z = 27;
DSHAFT_BASE_HEIGHT = 2;
DSHAFT_BASE_R = 3;
DSHAFT_HOLE_R = 1.21;
DSHAFT_BASE_TOP = DSHAFT_BASE_Z + DSHAFT_BASE_HEIGHT;

// D shaft key
DSHAFT_KEY_OFFSET = 1.65;
DSHAFT_KEY_SIZE = 2.2;

// Solid spacer disc between d shaft and threaded rod
SPACER_HEIGHT = 3.6;
SPACER_TOP = DSHAFT_BASE_TOP + SPACER_HEIGHT;

// Threaded rod
ROD_D = 5;
ROD_HEIGHT = 35;
ROD_PITCH = 3;
ROD_Z = SPACER_TOP + ROD_HEIGHT/2.3;

// Top key (+X side, joins d shaft / spacer / bottom of rod)
TOP_KEY_SIZE = [1, 1, 9.9];
TOP_KEY_POS = [0, 1.9, DSHAFT_BASE_Z + TOP_KEY_SIZE[2]/2];

// Bottom support on -X side, mirrors top key but shorter
SUPPORT_KEY_SIZE = [1, 1, 8.4];
SUPPORT_KEY_POS = [0, -1.9, DSHAFT_BASE_Z + SUPPORT_KEY_SIZE[2]/2];

module dShaftBase() {
    difference() {
        translate([0, 0, DSHAFT_BASE_Z])
            cylinder(DSHAFT_BASE_HEIGHT, DSHAFT_BASE_R, DSHAFT_BASE_R);
translate([0, 0, DSHAFT_BASE_Z])
            cylinder(DSHAFT_BASE_HEIGHT+5, DSHAFT_HOLE_R, DSHAFT_HOLE_R);
    }
}
        
module dShaftKey() {
    translate([DSHAFT_KEY_OFFSET, 0, DSHAFT_BASE_Z + DSHAFT_KEY_SIZE/2+1.4])
        cube([DSHAFT_KEY_SIZE,DSHAFT_KEY_SIZE+0.2,5], center=true);
}

module spacer() {
difference(){
    translate([0, 0, DSHAFT_BASE_TOP])
        cylinder(SPACER_HEIGHT, DSHAFT_BASE_R, DSHAFT_BASE_R);
        translate([0, 0, DSHAFT_BASE_Z])
            cylinder(DSHAFT_BASE_HEIGHT+1, DSHAFT_HOLE_R, DSHAFT_HOLE_R);
        }
}


module topKey() {
    translate(TOP_KEY_POS)
        cube(TOP_KEY_SIZE, center=true);
}

module supportKey() {
    translate(SUPPORT_KEY_POS)
        cube(SUPPORT_KEY_SIZE, center=true);
}

module rod() {
difference(){
    translate([0, 0, ROD_Z])
        threaded_rod(d=ROD_D, height=ROD_HEIGHT, pitch=ROD_PITCH);
        translate([0,0,25])
cube([10,10,10],center=true);
        }
}

module screw() {
    dShaftBase();
    dShaftKey();
    spacer();
    topKey();
    supportKey();
    rod();
}

screw();
```

### Elevator
```
include <BOSL2/std.scad>
include <BOSL2/threading.scad>

$fa = 0.5;
$fs = 0.01;

// Threaded nut in middle
NUT_Z = 32;
NUT_WIDTH = 5.5;
NUT_ID = 5;
NUT_HEIGHT = 5;
NUT_PITCH = 3;
NUT_SLOP = 0.11;

// Square block around the nut
BLOCK_SIZE = [11, 6.7, 5];
BLOCK_HOLE_R = 2.5;

// Side pins
PIN_OFFSET = 7;
PIN_LENGTH = 3;
PIN_R = 1;

module elevatorNut() {
    translate([0, 0, NUT_Z])
        threaded_nut(shape="square", nutwidth=NUT_WIDTH, id=NUT_ID,
                     h=NUT_HEIGHT, pitch=NUT_PITCH, $slop=NUT_SLOP);
}

module elevatorBlock() {
    translate([0, 0, NUT_Z])
        difference() {
            cube(BLOCK_SIZE, center=true);
            cylinder(BLOCK_SIZE.z, BLOCK_HOLE_R, BLOCK_HOLE_R, center=true);
        }
}

module elevatorPins() {
    translate([0, 0, NUT_Z])
        xcopies(spacing=PIN_OFFSET * 2, n=2)
            rotate([0, 90, 0])
                cylinder(PIN_LENGTH, PIN_R, PIN_R, center=true);
}

module elevator() {
    elevatorNut();
    elevatorBlock();
    elevatorPins();
}

elevator();
```

# Critical Reflection
## A printed D shaft socket
**Pros**
- The coupling between motor and screw is part of the screw, so there is no set screw and no glue
- The socket, the spacer and the keys are five numbers, which made ten versions in one day possible
- A screw costs very little to print, so it can be treated as a wear part

**Cons**
- A hole of 2.4 mm printed upright in PETG is only a few extrusion lines across, so its real size depends on the slicer as much as on the file. That is one likely reason the hole had to be tried several times
- The socket is now only 2 mm tall, so all the torque passes through 2 mm of plastic
- The names of the exports say what was changed but not by how much, and the SCAD file keeps only the last values. The numbers between v1 and v5 are not recoverable from the folder

## Opening the nut and not the screw
The last change of the day went into the nut. Raising the BOSL2 slop from 0.08 to 0.11 makes every nut a little looser on every screw. That is the cheaper fix, because the nut is the smaller part and the same change applies to all six actuators at once. The cost is play. A looser nut lets the elevator tilt a little more in the 7 mm channel, and that tilt is passed on to the lifter and the button stack above it.
