# Goals
- Replace the minkowski rounded casing of the first workbook with three flat shells that each sit on the print bed on a flat face
- Join the shells with printed snap fit features so the device opens by hand and needs no glue or screws
- Fix the six pin positions once, in all three shells, so every later actuator part can rely on them

# Description
The casing of the first workbook was one large rounded body with a separate top tray (see [[5. Entry Prototype of entire exterior casing]] and [[11. Creative Presentation of Device Orientation and Device Casing Adjustments]]). In the last days of December 2025 it was rebuilt as three shells of the same footprint that stack on top of each other. The bottom shell carries the actuators, the middle shell is an open ring that gives height for the electronics, and the top shell has the six round openings for the braille caps.

All three shells share one set of numbers. The footprint is 205 by 140 mm, the wall is 3 mm and the four vertical corners are chamfered by 10 mm. The six pin positions sit at X equal to minus 65, 0 and 65 mm and Y equal to plus and minus 32.5 mm. The parameters of the top and middle shells are identical in the SCAD files of late December 2025 and in the files saved again in May 2026, which is the clearest sign that this part of the redesign was right early on.

Reading the dates back, the three shells were drawn in one week, and most of that week was the evening of 25 December. The only geometry that moved afterwards was the snap fit. The middle shell lost 5 mm of tab height between 25 and 28 December, and the tabs and grooves of the bottom shell were exported twice more as tests on 4 May before the file was saved under the name AdjustedCubesandTriangles. The footprint, the wall and the six positions were never touched. `SEST_PIN_HOLES.stl` of 3 February is worth noting as a habit. Instead of printing a 205 mm shell to check whether six actuators line up, only the six sockets were printed at their true spacing.

One export needs a second look. `topCasingnoHull.stl` has a bounding box 348 mm tall, so it contains geometry that was never meant to be printed.

## Snap fit with tabs and triangle ridges
![[MooMooRedesign_21_snap_fit_cube_and_triangle.png|520]]
Cut out of one long wall seen from inside the casing. The tab of the bottom shell stands 5 mm above its rim. The triangle ridge of the middle shell sits just above the lower edge of its wall. The round post on the right is one of the fixed Raspberry Pi posts of the 9 May bottom shell

Each joint has two halves. One shell carries a tab of 4 by 8 by 15 mm that stands 5 mm proud of its rim and has a triangular groove cut across it. The shell that slides over it carries a triangular ridge in the same place. The groove is a three sided prism of radius 2.7 mm and 10.5 mm long. The ridge that enters it is a three sided prism of radius 2 mm and 9.6 mm long on the middle shell, and of radius 2.25 mm and 9.8 mm long on the top shell. That leaves 0.45 to 0.7 mm of clearance around the ridge. There are eight joints per seam, two on each short wall at Y equal to plus and minus 30 mm and two on each long wall at X equal to plus and minus 50 mm.

## Code
### Top shell
```
include <BOSL2/std.scad>
$fa = 1;
$fs = 0.4;
// ---- Main Side Lengths ----
LENGTH = 205;
WIDTH = 140;
HEIGHT = 40;
// ---- Rounding ---- 
ROUNDING = 10;
// ---- Edge Thickness ----
EDGE_THICKNESS = 3;
EDGE_THICKNESS_ATTACHMENT = 2;
// ---- Pin holes (6 total) ----
HOLE_H = 35;
HOLE_R = 22;
HOLE_Z = 25;
HOLE_POS = [
  [  0,  32.5],
  [  0, -32.5],
  [ -65,  32.5],
  [ -65, -32.5],
  [  65,  32.5],
  [  65, -32.5]
];
// ---- Hole supports (rings at top) ----
SUP_Z = 25;
SUP_OUT_H = 15;
SUP_OUT_R = 22.5;
SUP_IN_H = 15;
SUP_IN_R = 20.5;
// ---- Shape holder holes (front/back cubes) ----
HOLDER_CUBE_EDGE = 10;
FRONT_HOLDER_POS = [-102.5, 0, 15];
BACK_HOLDER_POS  = [ 102.5, 0, 15];
// ---- Shape Holder Support ----
FRONT_SUPPORT_POS = [-102.5, 0, 20];
BACK_SUPPORT_POS  = [ 102.5, 0, 20];
// ---- Grip dots ----
DOT_R = 1;
DOT_POS = [
  // attachment cube (right)
  [ 99,   0, 25],
  [ 99,   0, 15],
  [ 99,   5, 20],
  [ 99,  -5, 20],
  // attachment cube (left)
  [-99,   0, 25],
  [-99,   0, 15],
  [-99,   5, 20],
  [-99,  -5, 20]
];
// ---- Triangle marker positions ----
TRIANGLE_HEIGHT = 9.8;
TRIANGLE_Z = 2.2;
TRIANGLE_RADIUS = 2.25;
TRIANGLE_POSITIONS = [
  // FRONT - 2 triangles at equal distance from center
  [[-99, -30], [90, 0, 0]],     // front left triangle
  [[-99,  30], [90, 0, 0]],     // front right triangle
  // BACK - 2 triangles at equal distance from center
  [[99, -30], [90, 0, 180]],    // back left triangle
  [[99,  30], [90, 0, 180]],    // back right triangle
  // sides remain the same
  [[50, 66.5], [90, 0, -90]],   // right front
  [[-50, 66.5], [90, 0, -90]],  // left front
  [[50, -66.5], [90, 0, 90]],   // right back
  [[-50, -66.5], [90, 0, 90]]   // left back
];
// =============== MODULES ===============
module holes() {
  for (p = HOLE_POS)
    translate([p[0], p[1], HOLE_Z])
      cylinder(h=HOLE_H, r=HOLE_R, anchor=BOT);
}
module holeSupport() {
  for (p = HOLE_POS)
    difference() {
      translate([p[0], p[1], SUP_Z])
        cylinder(h=SUP_OUT_H, r=SUP_OUT_R, anchor=BOT);
      translate([p[0], p[1], SUP_Z])
        cylinder(h=SUP_IN_H, r=SUP_IN_R, anchor=BOT);
    }
}
module front_shape_holder_hole() {
  translate(FRONT_HOLDER_POS) 
    cube(HOLDER_CUBE_EDGE, anchor=BOT);
}
module back_shape_holder_hole() {
  translate(BACK_HOLDER_POS) 
    cube(HOLDER_CUBE_EDGE, anchor=BOT);
}
module frontShapeHolderSupport() {
  translate(FRONT_SUPPORT_POS) 
    rotate([0, 90, 0])
      difference() {
        cube(HOLDER_CUBE_EDGE + EDGE_THICKNESS_ATTACHMENT, anchor=BOT);
        cube([HOLDER_CUBE_EDGE, HOLDER_CUBE_EDGE, HOLDER_CUBE_EDGE + 2], anchor=BOT);
      }
}
module backShapeHolderSupport() {
  translate(BACK_SUPPORT_POS) 
    rotate([0, -90, 0])
      difference() {
        cube(HOLDER_CUBE_EDGE + EDGE_THICKNESS_ATTACHMENT, anchor=BOT);
        cube([HOLDER_CUBE_EDGE, HOLDER_CUBE_EDGE, HOLDER_CUBE_EDGE + 2], anchor=BOT);
      }
}
module casing(length, width, height, rounding) {
  cuboid([length, width, height], 
    anchor=BOT,
    chamfer=rounding,
    edges=[TOP, FRONT+RIGHT, FRONT+LEFT, BACK+RIGHT, BACK+LEFT],
    $fn=128
  );
}
module gripDots() {
  for (p = DOT_POS)
    translate(p) sphere(r=DOT_R);
}
module triangleMarkers() {
  for (pos = TRIANGLE_POSITIONS)
    translate([pos[0][0], pos[0][1], TRIANGLE_Z])
      rotate(pos[1])
        cylinder(TRIANGLE_HEIGHT,TRIANGLE_RADIUS,TRIANGLE_RADIUS, anchor=CENTER, $fn=3);
}
// =============== MAIN ASSEMBLY ===============
// Main hollow casing
difference() {
  casing(LENGTH, WIDTH, HEIGHT, ROUNDING);
  casing(LENGTH - EDGE_THICKNESS*2, WIDTH - EDGE_THICKNESS*2, HEIGHT - EDGE_THICKNESS, ROUNDING - (EDGE_THICKNESS/2));
  holes();
  front_shape_holder_hole();
  back_shape_holder_hole();
}
// Add features
triangleMarkers();
gripDots();
holeSupport();
backShapeHolderSupport();
frontShapeHolderSupport();
```

### Middle shell
```
include <BOSL2/std.scad>

$fa = 1;
$fs = 0.4;

// ---- Main Side Lengths ----
LENGTH = 205;
WIDTH = 140;
HEIGHT = 64;

// ---- Rounding ----
ROUNDING = 10;

// ---- Edge Thickness ----
EDGE_THICKNESS = 3;
EDGE_THICKNESS_ATTACHMENT = 2;

// ---- BOTTOM Triangle marker settings (pegs) ----
BOTTOM_TRIANGLE_HEIGHT = 9.6;
BOTTOM_TRIANGLE_Z = 1.9;
BOTTOM_TRIANGLE_RADIUS = 2;

// ---- TOP Triangle marker settings (holes in cubes) ----
TOP_TRIANGLE_HEIGHT = 10.5;
TOP_TRIANGLE_Z = 1.8;  // (2.2 - 0.4)
TOP_TRIANGLE_RADIUS = 2.7;

// ---- BOTTOM Triangle marker positions (pegs on bottom part) ----
BOTTOM_TRIANGLE_POSITIONS = [
    // FRONT - 2 triangles at equal distance from center
    [[-98.45, -30], [90, 0, 0]],    // front left triangle
    [[-98.45, 30], [90, 0, 0]],     // front right triangle
    // BACK - 2 triangles at equal distance from center
    [[98.45, -30], [90, 0, 180]],   // back left triangle
    [[98.45, 30], [90, 0, 180]],    // back right triangle
    // sides
    [[50, 66], [90, 0, -90]],     // right front
    [[-50, 66], [90, 0, -90]],    // left front
    [[50, -66], [90, 0, 90]],     // right back
    [[-50, -66], [90, 0, 90]]     // left back
];

// ---- TOP Triangle marker positions (holes in top cubes) ----
TOP_TRIANGLE_POSITIONS = [
    // FRONT - 2 triangles at equal distance from center
    [[-98.45, -30], [90, 0, 0]],    // front left triangle
    [[-98.45, 30], [90, 0, 0]],     // front right triangle
    // BACK - 2 triangles at equal distance from center
    [[98.45, -30], [90, 0, 180]],   // back left triangle
    [[98.45, 30], [90, 0, 180]],    // back right triangle
    // sides
    [[50, 65.9], [90, 0, -90]],     // right front
    [[-50, 65.9], [90, 0, -90]],    // left front
    [[50, -65.9], [90, 0, 90]],     // right back
    [[-50, -65.9], [90, 0, 90]]     // left back
];

// ---- Snap-fit cube receivers ----
CUBE_WIDTH = 4;     // X dimension
CUBE_LENGTH = 8;    // Y dimension
CUBE_HEIGHT = 15;   // Z dimension (depth)
CUBE_Z = -1;
CUBE_HOLE_Z_OFFSET = -4.2;

CUBE_POSITIONS = [
    // FRONT - 2 cubes at equal distance from center
    [[-97.5, -30], [90, 0, 0]],     // front left cube
    [[-97.5, 30], [90, 0, 0]],      // front right cube
    // BACK - 2 cubes at equal distance from center
    [[97.5, -30], [90, 0, 180]],    // back left cube
    [[97.5, 30], [90, 0, 180]],     // back right cube
    // sides
    [[50, 65], [90, 0, -90]],       // right front
    [[-50, 65], [90, 0, -90]],      // left front
    [[50, -65], [90, 0, -90]],      // right back
    [[-50, -65], [90, 0, -90]]      // left back
];

// =============== MODULES ===============

module casing(length, width, height, rounding) {
    cuboid([length, width, height],
        anchor=BOT,
        chamfer=rounding,
        edges=[FRONT+RIGHT, FRONT+LEFT, BACK+RIGHT, BACK+LEFT],
        $fn=128
    );
}

// Module for BOTTOM triangles (pegs)
module bottomTriangleMarkers() {
    for (pos = BOTTOM_TRIANGLE_POSITIONS)
        translate([pos[0][0], pos[0][1], BOTTOM_TRIANGLE_Z])
            rotate(pos[1])
                cylinder(BOTTOM_TRIANGLE_HEIGHT, BOTTOM_TRIANGLE_RADIUS, BOTTOM_TRIANGLE_RADIUS, anchor=CENTER, $fn=3);
}

// Module for TOP triangles (used as holes in cubes)
module topTriangleMarkers() {
    for (pos = TOP_TRIANGLE_POSITIONS)
        translate([pos[0][0], pos[0][1], TOP_TRIANGLE_Z])
            rotate(pos[1])
                cylinder(TOP_TRIANGLE_HEIGHT, TOP_TRIANGLE_RADIUS, TOP_TRIANGLE_RADIUS, anchor=CENTER, $fn=3);
}

module snapCubesWithHoles() {
    for (pos = CUBE_POSITIONS)
        translate([pos[0][0], pos[0][1], CUBE_Z])
            rotate(pos[1])
                cube([CUBE_WIDTH, CUBE_LENGTH, CUBE_HEIGHT], anchor=CENTER);
}

// =============== MAIN ASSEMBLY ===============

// Hollow casing
difference() {
    casing(LENGTH, WIDTH, HEIGHT, ROUNDING);
    casing(LENGTH - EDGE_THICKNESS*2, WIDTH - EDGE_THICKNESS*2, HEIGHT + EDGE_THICKNESS*2, ROUNDING - (EDGE_THICKNESS/2));
}

// Bottom snap-fit structures (bottom triangles/pegs)
bottomTriangleMarkers();

// Top snap-fit structures (cubes with triangular holes - mirrored)
translate([0, 0, HEIGHT])
    mirror([0, 0, 1])
        difference() {
            snapCubesWithHoles();
            // Triangular holes using TOP triangle positions
            translate([0, 0, CUBE_HOLE_Z_OFFSET])
                topTriangleMarkers();
        }
```

# Critical Reflection
## Flat shells against the rounded body
The first casing was built with minkowski and a sphere, which gave a soft shape but needed supports, a raft and sanding (see [[12. Sanding Techniques and Finishing 3D models]]). The new shells use chamfers on the top edges and on the four vertical corners only. Every outer face is flat or at 45 degrees, so each shell can sit on the bed on its closed face.

**Pros**
- Three shells of 40, 64 and 40 mm each fit the 210 or 220 mm deep bed recorded in the slicer projects of May 2026
- The device opens by hand at two seams, so the actuators and the electronics can be reached separately
- The six positions are shared numbers, so a change to a socket in the bottom shell cannot drift away from the opening above it in the top shell

**Cons**
- The rounded character of the first device is gone from the body. It now has to come from the head and tail parts of step 25
- The tabs and grooves of the bottom shell were still being exported as tests on 4 May 2026, four months after the shells were drawn, which suggests the first values did not carry over to the printer and material used in May

## The height of the tabs
The tabs were first 10 mm proud of the rim and were cut to 5 mm three days later.
