# Goals
- Design the exterior casing of the device as well as means of assembly of such casing
- Design a pin according to the braille standards

# Description
The current design proposal visualizes shape of the device. There are multiple things to consider while designing an exterior casing such as usability, general shape, durability and safety which will be taken into account while creating device.

# Prototyping
The early sketch was created to visualize the casing: 
![[PENUP_20250425_200018.jpg]]
Casing Compartment Sketch

The usability of the device suppose to bring comfort of interaction to the user. The parts especially the top pins suppose to be easily identifiable and well articulated whether they are up or down. 
The casing in general suppose to be durable to be able to hold some degree of more intense usage. Because of that the walls of the device has been made thicker to withstand some degree of regular use wearing. 
To address haptic cognition as well as safety the corners and edges of the devices has been rounded. That ensures that there aren't any sharp surfaces but also improve haptic recognition and centers focus only on the pins which have sharp edges. 
Because of the printing time of one piece (~30h) and modularity considerations the casing was divided into 3 pieces: 
- Top Cover
- Middle Cover
- Pin Holder Tray
- Bottom Cover

## Top Cover
Top casing function is to provide a socket (opening hole) for the braille pin. Considering pin design both top surface of the casing and flat surface of the braille pin suppose form a flat surface. Through the holes the braille pin will move up and down according the the braille symbol requirements.

### Code
```
// ===================================
// Curved Top Cover
// ===================================

$fn = 100;  // global smoothness

// ---- Minkowski kernel / base ----
KERNEL_SPH_R     = 10;                // rounding radius
TOP_BASE_SIZE    = [185, 120, 100];   // large block you rounded
TOP_BASE_Z       = 100;               // z-offset of that block

// ---- Frame plate (inset frame difference) ----
FRAME_OUTER      = [185, 120, 5];
FRAME_INNER      = [180, 115, 10];

// ---- Big clearance box to carve the top ----
BIG_CUT1_SIZE    = [180, 115, 141];
BIG_CUT1_Z       = 84;

BIG_CUT2_SIZE    = [300, 300, 105];
BIG_CUT2_Z       = -22;

// ---- Elevated "difference cube" stack ----
STACK_Z          = 80;
STACK_OUTER      = [210, 140, 100];

STACK_TOP_Z      = 46;                // inner sandwich at the top
STACK_SHEET_OUT  = [211, 141, 10];
STACK_SHEET_IN   = [190, 122, 10];

// ---- Round holes array ----
HOLE_H           = 35;
HOLE_R           = 22;
HOLE_Z           = 15;
HOLE_XS          = [-65, 0, 65];
HOLE_YS          = [-32.5, 32.5];

// ==================== Modules ====================

module top_surface_block() {
  // Your original topSuface()
  minkowski() {
    translate([0,0,TOP_BASE_Z])
      cube(TOP_BASE_SIZE, center=true);
    sphere(r=KERNEL_SPH_R, $fn=20);
  }
}

module frame_plate() {
  // Your main(): a thin frame via difference
  difference() {
    cube(FRAME_OUTER, center=true);
    cube(FRAME_INNER, center=true);
  }
}

module holes_block() {
  // Your holes(): 3x2 grid
  for (x = HOLE_XS)
    for (y = HOLE_YS)
      translate([x, y, HOLE_Z])
        cylinder(h=HOLE_H, r=HOLE_R, center=true);
}

module stacked_difference_cubes() {
  // Your differenceCube(): big box minus a thin sheet sandwich
  translate([0,0,STACK_Z])
    difference() {
      cube(STACK_OUTER, center=true);

      translate([0,0,STACK_TOP_Z])
        difference() {
          cube(STACK_SHEET_OUT, center=true);
          cube(STACK_SHEET_IN,  center=true);
        }
    }
}

// ==================== Final Shape ====================

module curved_top_panel() {
  // Your final: minkowski of a complex difference()
  minkowski() {
    difference() {
      top_surface_block();               // main rounded source

      translate([0,0,31]) frame_plate(); // the inset frame carving

      stacked_difference_cubes();        // elevated diff stack

      translate([0,0,150]) holes_block();// hole cluster (shifted up)

      // big carves
      translate([0,0,BIG_CUT1_Z]) cube(BIG_CUT1_SIZE, center=true);
      translate([0,0,BIG_CUT2_Z]) cube(BIG_CUT2_SIZE, center=true);
    }
  }
}

// ---------- Entry ----------
curved_top_panel();
```
## Middle Cover
Because of the device modularity the middle part of the casing acts like a connector between top and bottom cover. The division was done to divide the printing time and give modular possibilities to adjust height in case of different electronic parts or alternative design.
### Image
![[Pasted image 20240829201842.png]]
### Code
```
// ===================================
// Middle Cover
// ===================================

$fn = 100;

// ---- Minkowski kernel + base block ----
KERNEL_R         = 10;                     // rounding radius
TOP_BASE_SIZE    = [185, 120, 141];        // rounded block size
TOP_BASE_Z       = 100;                    // its Z offset

// ---- Frame "main" (difference of two plates) ----
FRAME_OUTER      = [185, 120, 5];
FRAME_INNER      = [180, 115, 10];
FRAME_PLATE_Z    = 31;                     // where frame cuts the shell

// ---- Difference cube stack (rotated + translated later) ----
STACK_OUTER      = [210, 140, 110];
STACK_INNER      = [192, 124,  13];
STACK_INNER_Z    = 50;                     // inner sheet offset *inside* the stack
STACK_BASE_Z     = -200;                   // base shift used inside the module
STACK_XFORM_ROT  = [0,180,0];              // transform done at assembly
STACK_XFORM_Z    = 70;                     // ...then translated up

// ---- Screw holes (4x at corners) ----
SCREW_H          = 30;
SCREW_R          = 3.55;
SCREW_Z          = 30;
SCREW_POS        = [ [ 93, -62],
                     [ 93,  62],
                     [-93,  62],
                     [-93, -62] ];

// ---- “Delete top part” & bottom carve ----
CUT_TOP_SIZE     = [180, 115, 141];
CUT_TOP_Z        = 100;

CUT_BOTTOM_SIZE  = [300, 300, 105];
CUT_BOTTOM_Z     = -22;

// ==================== Modules ====================

// Original: topSuface()
module top_surface_block() {
  minkowski() {
    translate([0,0,TOP_BASE_Z])
      cube(TOP_BASE_SIZE, center=true);
    sphere(r=KERNEL_R, $fn=20);
  }
}

// Original: main()
module frame_plate() {
  difference() {
    cube(FRAME_OUTER, center=true);
    cube(FRAME_INNER, center=true);
  }
}

// Original: differenceCube()
module difference_stack() {
  translate([0,0,STACK_BASE_Z])
    difference() {
      cube(STACK_OUTER, center=true);
      translate([0,0,STACK_INNER_Z])
        cube(STACK_INNER, center=true);
    }
}

module screw_holes() {
  for (p = SCREW_POS)
    translate([p[0], p[1], SCREW_Z])
      cylinder(h=SCREW_H, r=SCREW_R); // not centered (matches original)
}

// ==================== Final Assembly ====================

module curved_top_assembly() {
  // Your original final structure: minkowski of a complex difference()
  minkowski() {
    difference() {
      top_surface_block();

      // Frame plate carve
      translate([0,0,FRAME_PLATE_Z]) frame_plate();

      // Rotated + shifted difference cube stack
      rotate(STACK_XFORM_ROT)
        translate([0,0,STACK_XFORM_Z])
          difference_stack();

      // Screw holes
      screw_holes();

      // Delete top part
      translate([0,0,CUT_TOP_Z])    cube(CUT_TOP_SIZE, center=true);

      // Big bottom carve
      translate([0,0,CUT_BOTTOM_Z]) cube(CUT_BOTTOM_SIZE, center=true);
    }
  }
}

// ---------- Entry ----------
curved_top_assembly();


```

## Bottom Cover
The bottom cover should act as the support of the entire physical device structure. It will provide stability to the entire system as well as in the future iterations will hold electronic components of the system.
### Image
![[Pasted image 20240829205340.png]]
### Code
```
// ============================
// Bottom Cover
// ============================

$fn = 100;

// ---- Inner rounded shell (your topSuface) ----
KERNEL_R        = 10;
TOP_BASE_SIZE   = [185, 120, 38];
TOP_BASE_Z      = 100;

// ---- Frame plate (your main) ----
FRAME_OUTER     = [188, 123, 5];
FRAME_INNER     = [180, 115, 10];
FRAME_Z         = 88;

// ---- Legs (4 posts) ----
LEG_H           = 7;
LEG_R           = 3.55;
LEG_Z           = 125;
LEG_XY          = [ [-87,-52], [-87, 52], [ 87,-52], [ 87, 52] ];

// ---- Screw holes (4) ----
SCR_H           = 70;
SCR_R           = 3.55;
SCR_Z           = 80;
SCR_XY          = [ [ 93,-62], [ 93, 62], [-93, 62], [-93,-62] ];

// ---- Cleanup carves ----
CUT1_SIZE       = [182, 117, 50];
CUT1_Z          = 97;

CUT2_SIZE       = [300, 300, 105];
CUT2_Z          = 34;

// ==================== Modules ====================

// Original: topSuface()
module rounded_shell_block() {
  minkowski() {
    translate([0,0,TOP_BASE_Z])
      cube(TOP_BASE_SIZE, center=true);
    sphere(r=KERNEL_R, $fn=20);
  }
}

// Original: main()
module frame_plate() {
  difference() {
    cube(FRAME_OUTER, center=true);
    cube(FRAME_INNER, center=true);
  }
}

module legs() {
  for (p = LEG_XY)
    translate([p[0], p[1], LEG_Z])
      cylinder(h=LEG_H, r=LEG_R); // not centered, matches original
}

module screw_holes() {
  for (p = SCR_XY)
    translate([p[0], p[1], SCR_Z])
      cylinder(h=SCR_H, r=SCR_R); // not centered
}

// ==================== Final Assembly ====================

module bottom_cover() {
  // Outer minkowski() with a single child = no-op (kept to preserve intent)
  minkowski() {
    difference() {
      rounded_shell_block();                 // main rounded body
      legs();                                // legs subtracted
      translate([0,0,FRAME_Z]) frame_plate();// frame cut
      screw_holes();                         // screw holes
      // extra carves
      translate([0,0,CUT1_Z]) cube(CUT1_SIZE, center=true);
      translate([0,0,CUT2_Z]) cube(CUT2_SIZE, center=true);
    }
  }
}

// ---------- Entry ----------
bottom_cover();
```

# Critical Reflection
Despite minor measurement errors and manual adjustments during assembly, the casing prototype was successfully printed and assembled. A notable drawback is its excessive height, mainly stemming from the thickness of the bottom Cover; reducing this could lower the device's height by about 4cm. Furthermore, the pin holder tray design is redundant, as the pins should be positioned at the bottom of the cover. This adjustment would not only further reduce the device height by 2-3cm but also create a more efficient layout for the electronic components, thereby saving space.The middle section effectively connects the top and bottom cover parts, providing some options for adjustment.The top section is also well-crafted with no flaws.
