# Goals
- Assemble Proper size, 6 braille pin device
- Use ESP32 as microcontroller (WHY?)
- Use millis() to control the timing instead of delays

# Description
The design proposal introduces higher fidelity of the braille device with more detailed definition of a braille casing as well as additional functionality that will allow the pins to move simultaneously without any blocking in the code. The casing in the proposal will be used as a braille cell with 6 pins attached with the ability to test device as an middle grade prototype and understand improvement to be made. ESP32 with its cost effective solution and computational power replaced Arduino Uno. ESP32 offers more pins which are necessary for connection and will be tested to bring speech-to-text and text-to-speech functionality which is beyond capability of Arduino UNO. The code was modified to use millis() instead of delays to move pin separately in the loop rather the stop the execution of the code to wait until the pin will go up.

# Prototyping
The idea behind the prototyping was to create more stable and real version of the device that resembles final fidelity design with the usable fidelity.

## Casing
The previous 2 pin design proven to be very successful option therefore the casing will continue with the bottom tray as pin holder approach and extended braille cap silos. The only different will be in size where this iteration will introduce full size device.

FRAME_IN        = [40,115,10];
FRAME_Z         = 31;

STACK_RING_IN   = [198,131,10];

CUT_TOP_SIZE    = [191,125,141];
CUT_BOTTOM_Z    = -22;
CUT_BOTTOM_SIZE = [300,300,105];

// ==================== Modules ====================

module topSurface() {
  minkowski() {
    translate([0,0,TOP_CORE_Z])
      cube(TOP_CORE_SIZE, center=true);
    sphere(r=KERNEL_R, $fn=20);
  }
}

module holes() {
  for (p = HOLE_POS)
    translate([p[0], p[1], HOLE_Z])
      cylinder(h=HOLE_H, r=HOLE_R, center=true);
}

module holeSupport() {
  // ring supports around each hole position
  for (p = HOLE_POS) {
    difference() {
      translate([p[0], p[1], SUP_Z])
        cylinder(h=SUP_OUT_H, r=SUP_OUT_R, center=true);
      translate([p[0], p[1], SUP_Z])
        cylinder(h=SUP_IN_H,  r=SUP_IN_R,  center=true);
    }
  }
}

module gripDots() {
  for (p = DOTS_SIDE)      translate(p) sphere(r=DOT_R);
  for (p = DOTS_ATTACH_L)  translate(p) sphere(r=DOT_R);
  for (p = DOTS_ATTACH_R)  translate(p) sphere(r=DOT_R);
}

module framePlate() {
  difference() {
    cube(FRAME_OUT, center=true);
    cube(FRAME_IN,  center=true);
  }
}

module differenceCube() {
  translate([0,0,STACK_Z])
    difference() {
      cube(STACK_OUT, center=true);
      translate([0,0,STACK_RING_Z])
        difference() {
          cube(STACK_RING_OUT, center=true);
          cube(STACK_RING_IN,  center=true);
        }
    }
}

// ==================== Assembly ====================

module curved_multi_hole_panel() {
  union() {
    gripDots();
    holeSupport();

    minkowski() {
      difference() {
        topSurface();
        translate([0,0,FRAME_Z]) framePlate();
        differenceCube();
        translate([0,0,150]) holes();
        translate([0,0, CUT_TOP_Z])    cube(CUT_TOP_SIZE,    center=true);
        translate([0,0, CUT_BOTTOM_Z]) cube(CUT_BOTTOM_SIZE, center=true);
      }
    }
  }
}

// ---------- Entry ----------
curved_multi_hole_panel();

### ESP32 With Millis()
```
// ============================
// Six Buttons → Six DC Motors
// ============================

#include <Arduino.h>

// ---- Timing & behavior ----
const unsigned long RUN_MS      = 3000;  // run time per press
const unsigned long DEBOUNCE_MS = 40;    // debounce interval
const bool          ACTIVE_LOW  = true;  // INPUT_PULLUP: LOW = pressed

// ---- Motor+Button map ----
struct MotorUnit {
  uint8_t in1, in2, btn;
  bool    dir       = false;     // false: one way, true: the other
  bool    active    = false;     // currently moving
  bool    lastBtn   = HIGH;      // debounced level
  unsigned long tStart  = 0;     // motion start time
  unsigned long tBounce = 0;     // last change time (debounce)
};

// Your pins: (in1, in2, button)
MotorUnit M[] = {
  {27,26,17},  // Motor 1
  {33,25,16},  // Motor 2
  { 2, 0,18},  // Motor 3
  {22,23, 5},  // Motor 4
  {19,13,15},  // Motor 5
  {14,21,32},  // Motor 6
};
const int N = sizeof(M)/sizeof(M[0]);

// ==================== Helpers ====================

inline void motorStop(const MotorUnit& u) {
  digitalWrite(u.in1, LOW);
  digitalWrite(u.in2, LOW);
}

inline void motorDrive(const MotorUnit& u, bool dir) {
  // dir=false -> in1 LOW, in2 HIGH; dir=true -> reverse
  digitalWrite(u.in1, dir ? HIGH : LOW);
  digitalWrite(u.in2, dir ? LOW  : HIGH);
}

void handleUnit(MotorUnit& u, const char* label) {
  int raw = digitalRead(u.btn);

  // debounce
  if (raw != u.lastBtn) u.tBounce = millis();
  bool stable = (millis() - u.tBounce) > DEBOUNCE_MS;

  // start movement on press edge when idle
  if (!u.active && stable &&
      ((ACTIVE_LOW && u.lastBtn == HIGH && raw == LOW) ||
       (!ACTIVE_LOW && u.lastBtn == LOW && raw == HIGH))) {
    u.dir = !u.dir;            // toggle direction
    u.active = true;
    u.tStart = millis();
    Serial.print(label);
    Serial.println(u.dir ? " EXTEND" : " RETRACT");
  }

  // motion window (non-blocking)
  if (u.active) {
    unsigned long t = millis() - u.tStart;
    if (t <= RUN_MS) {
      motorDrive(u, u.dir);
    } else {
      motorStop(u);
      u.active = false;
      Serial.print(label);
      Serial.println(" STOP");
    }
  }

  u.lastBtn = raw;
}

// ==================== Setup ====================

void setup() {
  Serial.begin(9600);

  for (int i = 0; i < N; ++i) {
    pinMode(M[i].in1, OUTPUT);
    pinMode(M[i].in2, OUTPUT);
    pinMode(M[i].btn, INPUT_PULLUP);  // buttons to GND
    motorStop(M[i]);
    M[i].lastBtn  = digitalRead(M[i].btn);
    M[i].tBounce  = millis();
  }
}

// ==================== Loop ====================

void loop() {
  handleUnit(M[0], "M1:");
  handleUnit(M[1], "M2:");
  handleUnit(M[2], "M3:");
  handleUnit(M[3], "M4:");
  handleUnit(M[4], "M5:");
  handleUnit(M[5], "M6:");
}
```

# Critical Reflection
Esp32 reduced the cost of the device significantly. It was performing the same way as Arduino Uno offering more pins.
Generally the device performed its action well. Pins were moving up and down with moderate speed as well as the 6 pin device was performing as good as the 2 pin version. It was standing stable on the table and modularity concepts were snapping together well.
Millis code added functionality to the device to move pins simultaneously and the performance of the code was also very good. There were not problem with timings however motor blocks still occurred implying the need for additional sensor controlling motor position.
Another consideration is that device position, meaning front and back is not clearly articulated making it difficult to understand future letter haptically. The front and back of the device should be clearly articulated.
