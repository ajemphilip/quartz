# Tasks : ESP32 Text-to-Speech with Whispers OpenAI and Speech-to-Text using Deepgram

# Goals
- Create a prototype of the text-to-speech device to connect to Whispers API
- Create a prototype of speech-to-text to transcribe 

# Description
The design proposal focuses on the device with higher fidelity interaction that focuses on more interactive mode of communication that is based on voice and sounds. In this case two prototypes were created one based on the tutorial of https://www.youtube.com/watch?v=j0EEFXmikvk and used microphone, button and SD card module and the other tested MP3 module with SD card and speaker with the code generated by ChatGPT. The proposal not only tests initial user interaction with the storytelling by assessing components required for storytelling through ChatGPT but also its capabilities as prototyping assistant.

# Parts Used

- ESP32 S3

- 4 ohm speaker

### Code
```
#include <WiFi.h>
#include <WiFiClientSecure.h>
#include <HTTPClient.h>
#include <SPI.h>
#include <SD.h>
#include <Adafruit_VS1053.h>

// WiFi Credentials
const char* ssid = "iPhone";
const char* password = "pass123!";

// ⚠️ OpenAI API Key (Do not expose in production)
const char* OPENAI_API_KEY = "APIKEY";

// OpenAI API Endpoint
const char* OPENAI_TTS_URL = "https://api.openai.com/v1/audio/speech";

// MP3 file path on SD card
const char* mp3_filename = "/openai.mp3";

// ✅ Updated Pin Configuration for ESP32-S3 Dev Module
#define VS1053_CS 10    // VS1053 Chip Select
#define VS1053_DCS 9    // VS1053 Data Chip Select
#define VS1053_DREQ 5   // VS1053 Data Request (Interrupt)
#define SD_CS 6         // SD Card Chip Select
#define VS1053_RESET 3  // VS1053 Reset Pin

// Create VS1053 object
Adafruit_VS1053_FilePlayer musicPlayer = Adafruit_VS1053_FilePlayer(-1, VS1053_CS, VS1053_DCS, VS1053_DREQ, SD_CS);

// Secure WiFi client for HTTPS request
WiFiClientSecure client;

// 🔊 Play a short beep as confirmation
void playConfirmationBeep() {
  Serial.println("🔊 Playing confirmation beep...");
  musicPlayer.sineTest(0x44, 500);  // 440 Hz for 500ms
  Serial.println("✅ Beep complete.");
}

// 🎶 Fetch OpenAI TTS audio and store as MP3
bool fetchOpenAITTS(const char* text) {
  Serial.println("🌐 Connecting to OpenAI TTS API...");

  // JSON payload for OpenAI TTS request
  String jsonPayload = "{"
                       "\"model\": \"tts-1\","
                       "\"input\": \""
                       + String(text) + "\","
                                        "\"voice\": \"alloy\""
                                        "}";

  client.setInsecure();  // Ignore SSL verification
  HTTPClient https;
  https.begin(client, OPENAI_TTS_URL);
  https.addHeader("Content-Type", "application/json");
  https.addHeader("Authorization", String("Bearer ") + OPENAI_API_KEY);

  // Send POST request
  int httpResponseCode = https.POST(jsonPayload);

  if (httpResponseCode != 200) {
    Serial.print("❌ HTTP Response Code: ");
    Serial.println(httpResponseCode);
    Serial.println("⚠️ Error: Failed to fetch MP3 from OpenAI.");
    String response = https.getString();
    Serial.println("🔍 Full Response: " + response);
    https.end();
    return false;
  }

  Serial.println("✅ MP3 File received successfully!");

  // Open file on SD card for writing
  File file = SD.open(mp3_filename, FILE_WRITE);
  if (!file) {
    Serial.println("❌ Failed to open SD file for writing.");
    https.end();
    return false;
  }

  // 📥 Download and save the MP3 file
  WiFiClient* stream = https.getStreamPtr();
  uint8_t buffer[512];
  while (https.connected()) {
    int len = stream->available();
    if (len > 0) {
      int bytesRead = stream->readBytes(buffer, min(len, 512));
      file.write(buffer, bytesRead);
    }
  }

  file.close();
  https.end();

  Serial.println("✅ MP3 file saved to SD card.");

  return true;
}

// 📂 List all files on SD card
void listFilesOnSD() {
  Serial.println("📂 Listing files on SD card:");
  File root = SD.open("/");
  while (true) {
    File entry = root.openNextFile();
    if (!entry) break;
    Serial.print("📄 File: ");
    Serial.println(entry.name());
    entry.close();
  }
  Serial.println("✅ File listing complete.");
}

void setup() {
  Serial.begin(115200);

  // 🌐 Connect to WiFi
  WiFi.begin(ssid, password);
  Serial.print("🔄 Connecting to WiFi");
  while (WiFi.status() != WL_CONNECTED) {
    Serial.print(".");
    delay(500);
  }
  Serial.println("\n✅ Connected to WiFi!");

  // 🎵 Initialize VS1053
  Serial.println("🔄 Initializing VS1053...");
  pinMode(VS1053_RESET, OUTPUT);
  digitalWrite(VS1053_RESET, LOW);
  delay(100);
  digitalWrite(VS1053_RESET, HIGH);
  delay(100);

  if (!musicPlayer.begin()) {
    Serial.println("❌ VS1053 NOT FOUND! Check wiring.");
    while (1)
      ;
  }

  Serial.println("✅ VS1053 Initialized.");

  // 📀 Initialize SD card
  if (!SD.begin(SD_CS)) {
    Serial.println("❌ SD Card Initialization Failed!");
    while (1)
      ;
  }
  Serial.println("✅ SD Card Initialized.");

  // 🔊 Play short confirmation beep
  playConfirmationBeep();

  // 📂 List files before playing
  listFilesOnSD();

  // 🎶 Fetch OpenAI TTS audio
  Serial.println("🔄 Fetching OpenAI TTS audio...");
  if (!fetchOpenAITTS("Hello, welcome to OpenAI Text-to-Speech on ESP32!")) {
    Serial.println("❌ TTS Fetch failed!");
    return;
  }

  // 📂 List files again after download
  listFilesOnSD();

  // 🎵 Check if VS1053 is ready before playing
  if (!musicPlayer.readyForData()) {
    Serial.println("❌ VS1053 NOT READY! Check wiring.");
    return;
  }

  // 📏 Check MP3 file size before playback
  File checkFile = SD.open(mp3_filename);
  if (checkFile) {
    Serial.print("📏 MP3 File Size Before Playback: ");
    Serial.print(checkFile.size());
    Serial.println(" bytes");
    checkFile.close();
  } else {
    Serial.println("❌ ERROR: MP3 file not found before playback!");
    return;
  }

  // ▶️ Play the MP3 file
  Serial.println("🎶 Playing generated MP3 file...");
  if (!musicPlayer.playFullFile(mp3_filename)) {
    Serial.println("❌ Error playing MP3 file! Trying again...");
    delay(1000);
    if (!musicPlayer.playFullFile(mp3_filename)) {
      Serial.println("❌ Second attempt failed.");
    }
  } else {
    Serial.println("✅ Playback complete.");
  }
}

void loop() {
  // No need for a loop, playFullFile() blocks until done
}
```

# Critical Reflection
## Text-to-speech
After testing the technology worked however it is hardly extended to say that its usable. Firstly text to speech takes roughly 400 seconds to communicate with ChatGPT API, prepare the MP3 file, download it to the SD card and play through the speaker. ESP32 definitely has low computational power to accommodate such task making it unusable.
## Speech-to-text
Speech to text generally worked well with shorter phrases. The text response speed was very fast and the results were available after around 1-2 seconds making it a very robust and effective solution. On the other hand, the recording length was extremely limited making the solution not fully usable. The results only were coming back when the length of the recording did not exceed roughly 2 seconds which certainly takes away user experience and flexibility of expression.
## ChatGPT
In text-to-speech ChatGPT code generation definitely took some attempts to make it working. At first code generated prompted some errors which were related to hardware setup. Sometime it didn't understand the device connection making the whole system to fail. After specific prompt composure, explaing all the details about setup and functionality ChatGPT pointed a correct electronic board connection which helped to understand the gaps in the manufacturer tutorial which completly omit steps to connect MISO, MOSI and SD pins. Code was working after couple attempts however with the GPT suggestion the output should be back in around 2 second which wasn't true. On the other hand, it prompted working code which possibly can bring the prototyping and assistive device DIY making closer to community members.
## General Insight 
ESP32 with electronic components is definitely not a preferred choice when it comes to more demanding computational tasks. Despite its doing its work the limitations post a really important user experience gap such as latency and quality or lack of output as very inconvenient and inconsistent. Because of that device with higher computational power must be found to bring user experience to more acceptable level.
